# Phí Điền — Personal portfolio

Website portfolio tĩnh dùng HTML, CSS và JavaScript thuần, tối ưu để chạy trên GitHub Pages. Phần đầu trang có minh họa học viện anime gốc, lớp ánh sáng, cánh hoa và nhân vật riêng; hiệu ứng parallax chạy bằng CSS/JavaScript, không cần tải GIF nặng.

## Chạy thử

Mở `index.html` trực tiếp trong trình duyệt hoặc dùng một static server. Website không cần bước build.

## Cá nhân hóa

- Sửa tên, phần giới thiệu, dự án và liên kết trong `index.html`.
- Email liên hệ mẫu hiện là `hello@phidien.github.io`; thay bằng địa chỉ thật trước khi dùng.
- Chỉnh bảng màu, khoảng cách và giao diện trong `style.css`.
- Hiệu ứng sao, menu di động, nút lên đầu trang, hiệu ứng xuất hiện và âm thanh tổng hợp nằm trong `script.js`.
- Ảnh nền và nhân vật nằm trong `assets/academy-scene.webp` và `assets/academy-student.webp`.

Âm thanh chỉ phát sau khi khách nhấn nút. Tôn trọng cài đặt giảm chuyển động của thiết bị. Google Fonts là tùy chọn; khi mất mạng, font hệ thống sẽ được dùng.

## GitHub Pages

Repository: `betapmod/phidien.github.io`. Đặt ba tệp `index.html`, `style.css`, `script.js` ở thư mục gốc trên nhánh `main`. Bật Pages tại **Settings → Pages → Deploy from a branch → main → /(root)** nếu chưa bật.
